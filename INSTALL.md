# Установка и использование

Что за репозиторий, как им пользоваться, что чем закрывается. Для того, кто
берёт библиотеку себе, а не читает её исходники.

## Что это

Vector Shotcraft — **библиотека приёмов для продуктовых роликов**, а не
программа. Внутри три разных вещи:

1. **Справочник приёмов** — 157 карточек шотов с параметрами и подводными
   камнями (`references/cards/`), плюс русский индекс по ним
   (`references/cards-index.md`). Работает без установки: это markdown.
2. **Инструмент монтажа по битам** — `scripts/beat_grid.py`. Единственная
   часть, которой нужен интерпретатор и библиотеки.
3. **Методики** — монтаж по сетке битов (`references/beat-sync.md`) и
   категорийный словарь звука (`references/sfx-catalog.md`). Тоже текст.

Готового видеоконвейера здесь нет и не планируется: реализации приёмов пишутся
под свой стек. Что даёт репозиторий — **что** делать и **с какими числами**.

## Требования

- **Для справочника** — ничего, кроме возможности читать markdown.
- **Для инструмента бит-сетки** — Python 3.11+ и пакеты `librosa`, `soundfile`,
  `numpy`, `scipy`. Проверено на Python 3.13.
- **Для скриптов обслуживания** — только стандартная библиотека Python.
- ffmpeg — если будете сами резать аудио или собирать ролик (не требуется
  этим репозиторием).
- **Node** — не требуется. Если будете рендерить в Remotion, он вам понадобится,
  но это уже ваш проект, а не этот репозиторий.

## Быстрый старт

```bash
git clone https://github.com/Osmosy/vector-shotcraft.git
cd vector-shotcraft
```

### 1. Найти приёмы

```bash
less references/cards-index.md        # все 157: суть, когда брать, длительность
less references/cards/camera/crash-zoom-punch.md   # полный текст с параметрами
```

### 2. Поставить окружение для бит-сетки

```bash
uv venv ~/.venvs/shotcraft
uv pip install --python ~/.venvs/shotcraft/bin/python \
  librosa soundfile numpy scipy

# или без uv:
python3 -m venv ~/.venvs/shotcraft
~/.venvs/shotcraft/bin/pip install librosa soundfile numpy scipy
```

### 3. Посчитать сетку битов под свой трек

```bash
~/.venvs/shotcraft/bin/python scripts/beat_grid.py bgm.mp3 --fps 30 --json grid.json
```

Обязательно проверьте сам инструмент на синтетике с известным темпом — это
занимает около минуты и говорит, что сетка восстанавливается корректно:

```bash
~/.venvs/shotcraft/bin/python tests/test_beat_grid.py
```

Ожидаемый финал: `все случаи прошли`.

### 4. Наложить звук

Читаем `references/sfx-catalog.md`, качаем звуки по категориям (рекомендованный
источник — Mixkit, бесплатно и коммерчески), **сразу записываем источник
каждого файла** и прогоняем md5-дедупликацию.

## Что чем закрывается

| Задача | Чем |
|---|---|
| «Какой приём взять для смены раздела?» | `references/cards-index.md`, категория `transition` |
| «Сколько кадров займёт наезд камеры?» | полный текст карточки, раздел параметров |
| «Почему склейка не попадает в бит?» | `references/beat-sync.md` |
| «Какой звук на вылет карточки?» | `references/sfx-catalog.md`, категория |
| «Посчитать сетку под свой трек» | `scripts/beat_grid.py` |
| «Обновить карточки из апстрима» | `scripts/vendor_cards.py` |
| «Агент должен этим пользоваться сам» | `skills/vector-shotcraft/SKILL.md` |

## Обновление и проверки

Карточки обновляются из апстрима скриптом:

```bash
python3 scripts/vendor_cards.py            # скачать новые / изменившиеся
python3 scripts/vendor_cards.py --list     # только показать, что было бы скачано
python3 scripts/vendor_cards.py --only camera
```

Перед коммитом — две проверки (то же делает CI):

```bash
python3 scripts/validate.py
~/.venvs/shotcraft/bin/python tests/test_beat_grid.py
```

`validate.py` падает, если: апстримный текст карточки изменён (сверка по SHA1),
в индексе нет русских полей, ссылка ведёт в никуда, число в README разошлось с
фактом, пропала лицензия апстрима.

## Ограничения

- **Аудиофайлов в репозитории нет.** Категории — это знание, файлы — лицензии и
  вес. Скачиваете сами; запись источника обязательна, у 6 файлов апстрима
  источник не установлен.
- **Реализаций приёмов нет.** Карточка описывает приём и параметры; код — ваш.
- **Приёмы разобраны с чужих роликов.** Взято ремесло, не выражение; подробности
  и практический вывод в `NOTICE.md`.
- **Remotion под своей лицензией.** Крупным компаниям нужна платная; приёмы при
  этом переносимы в любой стек.
- **Инструмент откажется работать** на треке короче ~10 секунд или с малым
  числом ударов. Это честный отказ, а не сбой: сетка по 4 битам была бы ложью.
- **Живая запись с плавающим темпом** требует сегментной сетки — см.
  `references/beat-sync.md`.

## Где что менять

- Приёмы — `references/cards/` через `scripts/vendor_cards.py` (руками не
  править: валидатор поймает изменение апстримного текста).
- Русский индекс — `references/cards-index.md` генерируется; источник правок —
  скрипты `build_index.py` / `apply_translations.py`.
- Инструмент — `scripts/beat_grid.py`, проверки — `tests/test_beat_grid.py`.
- Навык для агента — `skills/vector-shotcraft/SKILL.md`, имя каталога должно
  совпадать с полем `name` во frontmatter (проверяется валидатором).

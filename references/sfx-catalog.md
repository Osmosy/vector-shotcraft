# Звуковой дизайн: категорийный словарь

Словарь для выбора звука. **Сначала категория, потом тембр** — не «найду что-то
подходящее», а «это движение камеры, значит `camera/`».

Перенесено из апстрима video-shotcraft (`references/sound-design.md`,
Apache-2.0, © Wei Yihao) как **категорийный индекс**. Аудиофайлы апстрима в этот
репозиторий не включены: категории — это знание, файлы — это лицензии и вес.
Где брать сами звуки — ниже.

## Главное правило: слово и категория — разные вещи

Словарь «типов ролика» — пять слов: **whoosh** (движение камеры),
**impact** (приземление), **riser** (подъём), **sparkle** (свет), **transition**
(переход). Это не имена каталогов:

| Слово | Категория | Почему так |
|---|---|---|
| whoosh | `transition/` | ктоши и переходы звучат одинаково — отдельного каталога нет |
| impact | `impact/` | совпадает |
| riser | `riser/` | совпадает |
| **sparkle** | **`light/`** | каталога `sparkle/` не существует |
| transition | `transition/` | совпадает с whoosh |

Остальные категории — **слой foley**: звук под конкретное видимое
действие, а не под тип ролика.

## Категории

| Категория | Что внутри | Когда открывать |
|---|---|---|
| `transition/` | whoosh, sweep, swoosh, ветер | движение камеры, смена сцены, влёт/вылет элементов |
| `impact/` | impact, thud, stomp, bass hit | приземление, тяжёлый бит, slam |
| `riser/` | нарастание | подводка к финалу, перед крупным планом |
| `camera/` | затвор, объектив, зум | «фотографический» кадр, crash zoom, фокус, iris |
| `ui/` | клик, переключатель, уведомление, pop | отклик интерфейса, смена темы, падение списка |
| `text/` | печатная машинка, клавиатура, письмо | печать текста, подчёркивание, обводка |
| `paper/` | бумага, страница, печать | перелистывание, разрыв, бумажная фактура |
| `film/` | проектор, плёнка, кассета, винил | трейлерный язык, плёночная серия, перемотка |
| `light/` | sparkle, световые эффекты | световой проход, включение, послесвечение |
| `data/` | glitch, ток, данные | HUD, потоковые данные, скелетон, сбой |
| `scifi/` | техно, космос, фоновый гул | космическое движение, системный фон (длинные сэмплы) |
| `mech/` | механика, индустрия, замок | сборка узлов, фиксация, деформация |
| `glass/` | стекло, осколки | переход через разбивание, жёсткая склейка |
| `fluid/` | чернила, вода, жидкость, частицы | чернильное открытие, засыпание частицами, пузыри |
| `crowd/` | толпа, аплодисменты, дыхание, сердце | финал с общим планом, ощущение презентации, напряжение |
| `counter/` | счётчик, прибор, часы, отсчёт | прокрутка чисел, показания, таймлайн |

Категория — **индекс поиска, а не критерий подбора**. Материальные звуки
(`glass/`, `crowd/`, `fluid/`) — это слой «под картинку»; для общих переходов
приоритет у `transition/` и `impact/`.

## Уровни

- **Базовый уровень** — 12 звуков, которые реально несут ролик: 2 переходных
  whoosh (быстрый/крупный), мягкий переход, snap-фиксация, короткий swoosh на
  титры, световой sparkle, клавиатура (длинный сэмпл, режется по абзацам),
  клик-затвор (камерный щелчок), riser на финал, impact-приземление, pop на
  падение элементов списка, мягкий подвод к сцене.
- **foley** — остальное. Берётся точечно, под конкретный видимый жест.

**Внимание при выборе `ui/`:** в этой категории смешаны настоящий механический
щелчок и синтетический отклик. Второй в рекламном ролике звучит «как в игре» —
это главный способ провалить звук. Слушать, не доверять имени файла.

## Где брать звуки

Категории — это знание, а файлов в репозитории нет. Порядок работы:

1. Идём в **Mixkit** (mixkit.co) — бесплатно, коммерчески, без обязательной
   атрибуции; там есть и музыка, и звук, и раздел cinematic SFX.
2. Качаем **под имена понятные**: `<категория>-<что>-<номер>.mp3`.
3. **Записываем источник сразу** — название трека и URL. Это не формальность:
   после массовой загрузки метаданные теряются, и обратно трек не найти.
4. **Прогоняем md5-дедупликацию** до подключения в проект. Один и тот же файл,
   скачанный дважды под разными именами, при монтаже «двойного сэмпла» даёт
   ровно ноль эффекта — а в проекте выглядит как два разных звука.
5. Звуки без подтверждённого источника **не идут в коммерческий ролик**.

Проверка дедупликации:

```bash
find assets/audio -name '*.mp3' -exec md5sum {} + | sort | awk '{print $1}' \
  | uniq -d
```

## Как ставить звук на таймлайн

1. **Сначала картинка.** Пока сцены меняются, звук всё равно переделывать.
   В апстриме звук начали ставить после ~30 итераций картинки; когда поменяли
   BGM и картинку в одном заходе — таблицу звуков пришлось делать заново.
2. **Потом BGM** — один трек на весь ролик, громкость около 0.34, чтобы
   остался запас под звуки. Затухание в начале и в конце.
3. **Потом точечные звуки** — таблица `{кадр, файл, громкость}` с комментарием
   к каждому кадру («whoosh на вылете карточки»). Не «на слух раскидать».
4. **Отдельно — слот под заказ.** У узнаваемых жестов (печать текста, падение строк)
   должен быть свой звук; общий swoosh их не закрывает.
5. Заканчивать **без BGM версией**: тот же таймлайн, BGM выключен, звуки
   остаются — нужна для площадок, где музыка не допускается.

## Чужая беда: чему не подражать

Из разбора апстрима (там это стоило трёх переделок за 34 минуты):

- Выбирать музыку **не в контексте ролика** («нравится на слух») — трек дважды
  забраковали. Слушать только подложенным под картинку.
- Брать «весёлое/красивое» вместо «как в рекламе» — критерий другой: закрыв
  глаза, должно звучать как презентация продукта, а не как мобильная игра.
- Игровые звуковые паки (синтетические pluck/bloop, мультяшные подскоки) в
  продуктовом ролике запрещены. Механический щелчок под реальный клик — можно.

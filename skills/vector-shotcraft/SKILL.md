# Vector Shotcraft

Русский прикладной слой к библиотеке приёмов продуктового видео. Источник —
открытый проект [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)
(Apache-2.0): 157 карточек шотов, 10 категорий, спецификации с точными
параметрами. Что здесь наше: русский индекс и глоссарий, методика монтажа по
битам с рабочим инструментом и тестами, категорийный словарь звука.

## Что в репозитории

| Где | Что |
|---|---|
| `references/cards/<категория>/*.md` | 157 карточек шотов, оригинальный текст как есть |
| `references/cards-index.md` | русский индекс: суть, когда брать, длительность, энергия |
| `references/beat-sync.md` | методика монтажа по сетке битов |
| `references/sfx-catalog.md` | категорийный словарь звука (16 категорий) |
| `scripts/beat_grid.py` | сетка битов: BPM, фаза, кадры, вердикт |
| `tests/test_beat_grid.py` | проверка сетки на синтетике с известным темпом |

## Как работать

### 1. Нужен приём под задачу

Читаем `references/cards-index.md` — там каждая карточка одной строкой: что
делает, когда брать, сколько длится, какая энергия. Найдя нужную, открываем
полный текст в `references/cards/<категория>/<имя>.md`: там параметры в кадрах,
кривые ускорения, точки-якоря и подводные камни, отмеченные автором.

Практический порядок при монтаже ролика:

1. **Открытие** — брать из `opening/` (1 кадр: бренд-линия, крановый подъём,
   поток линий, осколки, иконочное поле, орбитальное кольцо, луч-прожектор).
   Из них выбирается один, остальные пять — перебор.
2. **Тело** — `ui-entrance/` и `interaction/` (появление интерфейса, работа с
   ним), `data/` (числа и графики), `camera/` (движение в пространстве).
3. **Ритм** — `rhythm/` (монтажные приёмы) и `transition/` (стыки).
4. **Финал** — `outro/` (логотип, групповой кадр, свёртка).

Правила, вытекающие из самих карточек: тяжёлые приёмы (crash zoom, dolly-zoom,
взрыв-схема, пикирование) — не больше 1–2 раз за ролик; техника категории
`transition/` выбирается **после** раскадровки, под каждый стык отдельно.

### 2. Ролик монтируется под музыку

Порядок жёсткий: **музыка → сетка битов → раскадровка → монтаж**. Сетка
считается инструментом, кадры берутся из его вывода, а не пересчитываются
вручную (иначе накапливается дрейф до 38 кадров на двухминутном треке).

```bash
~/.venvs/shotcraft/bin/python <repo>/scripts/beat_grid.py bgm.mp3 --fps 30 --json grid.json
```

Читаем вердикт: остаток, отсев выбросов, полу/двойная сетка, покрытие ударов.
Метод и разбор вывода — `references/beat-sync.md`.

### 3. Накладывается звук

Категорийный словарь — `references/sfx-catalog.md`: сначала категория, потом
тембр. Файлов в репозитории нет намеренно (лицензии и вес), источник — Mixkit,
источник каждой загрузки записывается сразу. Порядок работ: сначала картинка,
потом BGM, потом точечные звуки по сетке битов.

## Границы

- Карточки — это приёмы и числа, а не готовый код. Реализацию под свой стек
  пишем сами: библиотека даёт, **что** и **с какими параметрами**, не даёт
  готовых компонентов.
- Приёмы сняты разбором чужих промо-роликов (Notion, Figma, Slack, Framer,
  Raycast, Perplexity, ClickUp, Bear, Pitch, Miro, Superhuman, Loom, а также
  работ отдельных моушн-дизайнеров). Взяты только приёмы, переписаны с нуля,
  брендовых элементов нет; у 48 из 157 карточек источник записан построчно в
  апстриме, у остальных — нет. Для коммерческого использования это значит:
  приемлемо, но с оглядкой; см. `NOTICE.md`.
- Аудиофайлы апстрима (в том числе те, чей источник не установлен) сюда не
  переносились.
- Remotion под собственной лицензией: физлицам и малым командам бесплатно,
  крупным компаниям нужна платная.

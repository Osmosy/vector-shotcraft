# Демонстрационная сборка: реальный продукт → монтаж по битам

Это не макет и не анимация «по мотивам»: ролик собран из **живых скриншотов
работающего продукта** (Zvec Studio, локальный сервер на `127.0.0.1:7860`) и
смонтирован строго по сетке битов, которую построил `scripts/beat_grid.py`.

## Что здесь доказывается

| Проверка | Результат |
|---|---|
| Монтаж стоит на битах | Расхождение склеек с узлами сетки — **0 кадров** (5/5 шотов) |
| Точность бит-сетки | Медиана отклонения ударов от узлов — **3.1 мс** при полкадре 16.7 мс |
| Сетка против известной истины | Кадры **0, 15, 30, 45…** — совпадают с истиной покадрово |
| Покрытие сильных ударов | **100%** (38/38) |
| Звук в ролике | AAC, 17.045 с, синхронизирован с картинкой |

## Состав

```
demo/
├── make_bgm.py         генератор BGM 120 BPM с ИЗВЕСТНОЙ истиной (k·0.5 с)
├── audio/bgm.wav       сгенерированный трек (истина задана кодом)
├── shots/              реальные скриншоты Zvec Studio (сняты через Chrome)
├── comp/Demo.tsx       компоненты: приёмы из карточек библиотеки
├── comp/Root.tsx       расписание шотов — читает кадры из out/grid.json
├── check_cuts.py       проверка готового ролика: склейки против сетки
└── out/demo.mp4        результат
```

## Запуск от начала до конца

```bash
cd demo

# 1. BGM с известным темпом (иначе не с чем сверять точность)
~/.venvs/shotcraft/bin/python make_bgm.py audio/bgm.wav

# 2. Сетка битов — единственное место, где секунды переводятся в кадры
~/.venvs/shotcraft/bin/python ../scripts/beat_grid.py audio/bgm.wav --fps 30 --json out/grid.json

# 3. Рабочая копия для рендера: Remotion не читает симлинки в public/,
#    поэтому файлы копируются (в git public/ не хранится)
mkdir -p public/shots
cp audio/bgm.wav public/bgm.wav
cp shots/*.png public/shots/

# 4. Рендер (Chrome: системный, т.к. chrome-headless-shell с remotion.media
#    в этой сети не скачивается — задан в remotion.config.ts; модули
#    подключаются симлинком на локальную установку Remotion)
ln -sfn ~/projects/OpenMontage/remotion-composer/node_modules node_modules
npx remotion render comp/index.tsx ShotcraftDemo out/demo.mp4

# 5. Проверка: склейки встали на биты? Возвращает 1, если монтаж разъехался,
#    поэтому эта же команда стоит в CI.
~/.venvs/shotcraft/bin/python check_cuts.py out/demo.mp4
```

## Приёмы — из карточек, а не выдуманы

| Приём | Карточка | Как применён |
|---|---|---|
| Панорама камеры | `camera/overhead-camera-moves` (B) | Пролёт только сдвигом, затем остановка; резкий пуш по интерфейсу читается как «камера не знает, что делает» |
| Резкий наезд | `camera/crash-zoom-punch` | Титры: резкий наезд за 6 кадров, откат 4%, затухающая тряска `14px·e^(−t/1.8)` |
| Счётчики | `data/counter-confetti` | easeOutQuart, заход заранее на 0.04 с, перелёт масштаба 1.3 → 1 |
| Индикаторы | `data/gauge-readout-moves` | каскад: 4 кадра между тремя значениями |

## Что демо вскрыло (и почему это ценно)

1. **Фаза из бит-трекера опаздывает на ~20 мс.** `beat_track` систематически
   отстаёт от реального удара, и лаг не уходит при уменьшении hop_length —
   значит это лаг алгоритма, а не квантование. Монтаж получался «почти в такт»;
   лечение — поиск фазы по максимуму энергии сигнала. Подробности и таблица
   замеров: `references/beat-sync.md`.
2. **Затухание перед склейкой убивает ритм.** Fade на 4 кадра даёт первый шаг
   в 25% — визуально более сильное событие, чем сама склейка. Проверка ролика
   показывала пики на 3 кадра раньше бита.
3. **Всё, что появляется в кадре, должно попадать в узел сетки.** Текст с
   задержкой +2 и +5 кадров читался проверкой как события вне сетки.
4. **`Easing.quart` отсутствует в Remotion 4.0.484** — падение
   `easing is not a function`; заменено точным Безье `(0.25, 1, 0.5, 1)`.

## Ограничения

- Скриншоты сняты с локального продукта и содержат его данные; в кадре видны
  реальные заголовки документов (названия навыков и файлов) — не персональные
  данные.
- Ролик демонстрационный: 17 с, 6 шотов, 1600×900. Для продакшена меняется
  расписание в `comp/Root.tsx` и подставляются нужные скриншоты.
- Remotion требует Node и headless-браузер; лицензия Remotion для компаний
  платная (см. `THIRD_PARTY_LICENSES/`).
